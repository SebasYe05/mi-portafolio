# 🎮 Portfolio tipo Consola — Sebastián Sotomayor

¡Bienvenido! Este es mi portafolio interactivo, una recreación funcional de una consola clásica (inspirada en Nintendo DS) desarrollada con **React**, **Tailwind CSS** y **Framer Motion**.

El objetivo es presentar mis habilidades, experiencia y proyectos de una manera nostálgica, creativa y divertida.

**Demo en vivo:** [https://sebasye05.github.io/mi-portafolio/](https://sebasye05.github.io/mi-portafolio/)

---

## 🛠️ Stack del Portafolio

- **Frontend:** React 19 + Vite
- **Estilos:** Tailwind CSS 4
- **Animaciones:** Framer Motion
- **Iconos:** React Icons
- **Arquitectura:** Componentes modulares + data-driven content

---

## 📦 Instalación y uso

```bash
git clone https://github.com/SebasYe05/mi-portafolio.git
cd mi-portafolio
npm install
npm run dev
```

Abre `http://localhost:5173`

---

## ✨ Características

- Interfaz dual-screen tipo consola interactiva
- Navegación completa con D-pad y botones A/B
- Scroll controlado por cruceta en vistas de detalle
- Datos actualizados (experiencia, proyectos, skills, certificaciones)
- Diseño responsivo y visual moderno
- Tema inspirado en hardware clásico
